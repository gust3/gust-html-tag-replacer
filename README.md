# 🔄 Gust HTML Tag Replacer

**Gust HTML Tag Replacer** — это легковесное и удобное расширение для браузера, созданное для веб-разработчиков, контент-менеджеров и копирайтеров. Оно помогает мгновенно менять HTML-теги в выделенном коде прямо внутри визуальных редакторов (например, TinyMCE) или стандартных текстовых полей.

Расширение доступно для **Firefox** и **Opera**, а также совместимо с другими браузерами на базе Chromium (Chrome, Yandex, Edge) через режим разработчика.

---

## 🚀 Основные возможности

*   ⚡ **Мгновенная замена:** Выделите HTML-код и нажмите `Ctrl+Shift+R` (или `Cmd+Shift+R` на Mac), чтобы заменить теги за секунду.
*   🔤 **Все регистры:** Специальная галочка позволяет заменять теги независимо от их регистра (`<strong>`, `<STRONG>`, `<Strong>`) с помощью одного правила.
*   🪄 **Умные пары тегов:** Не нужно отдельно вводить закрывающий тег — расширение автоматически подставит его на основе открывающего.
*   📚 **База правил:** Все созданные правила сохраняются в общую базу. Вы можете быстро включать и выключать их галочками, не вводя текст заново.
*   🎯 **Работает везде:** Умный поиск полей ввода распознает `textarea`, `contenteditable` и даже сложные редакторы внутри `iframe`.
*   🌍 **Локализация:** Полная поддержка русского и английского языков интерфейса.

---

## 📦 Структура репозитория

В репозитории представлены исходные коды и готовые сборки для разных платформ:

*   📁 `/src/` — Исходный код расширения (общий для всех платформ).
*   📁 `/firefox/` — Сборка, адаптированная для Firefox (с добавленным `browser_specific_settings.gecko`).
*   📁 `/opera/` — Сборка для Opera и других Chromium-браузеров.
*   📁 `/zips/` — Готовые `.zip` архивы для ручной установки или загрузки в магазины расширений.

## 🛠 Установка

### 🦊 Firefox
Самый простой способ — установить расширение из официального магазина:
👉 **[Установить из Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/gust-html-tag-replacer/)** *(Замени ссылку, когда она появится)*

### 🎭 Opera
Установите расширение из каталога Opera Add-ons:
👉 **[Установить из Opera Add-ons](https://addons.opera.com/ru/extensions/details/gust-html-tag-replacer/)** *(Замени ссылку, когда она появится)*

### 🌐 Chrome / Yandex / Opera (Ручная установка)
Если вы хотите установить расширение вручную (например, из ZIP-архива или исходников):
1. Скачайте и распакуйте ZIP-архив из папки `/zips/`.
2. Откройте браузер и перейдите на страницу управления расширениями:
   * Opera: `opera://extensions/`
   * Chrome: `chrome://extensions/`
   * Yandex: `browser://extensions/`
3. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку с распакованным расширением.
6. Готово! Закрепите иконку на панели браузера.

---

## 💻 Использование

1. Выделите HTML-код на странице (в текстовом поле или визуальном редакторе).
2. Нажмите `Ctrl+Shift+R` или кликните правой кнопкой мыши и выберите **«Gust: Заменить теги в выделенном»**.
3. Готово! Все теги заменены согласно вашим правилам.
4. Нажмите на иконку расширения, чтобы добавить новые правила, включить/выключить игнорирование регистра или посмотреть базу сохранённых правил.
